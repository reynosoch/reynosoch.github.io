## Reynoso Transcribe

[Abrir transcriptor de audio e imágenes](https://reynosoch.github.io/transcribe/).

Acepta archivos de audio / video compatibles con el navegador, micrófono, enlaces directos HTTPS con CORS e imágenes o capturas pegadas. Whisper transcribe voz localmente; Tesseract extrae texto de imágenes. Ofrece mejora de voz baja sin recorte por volumen, selección de canal, texto editable, TXT y subtítulos SRT.

Código y documentación: [`transcribe/README.md`](transcribe/README.md). Publicación estática desde `main` con el despliegue GitHub Pages ya configurado. Se conserva `index.html` de la raíz.
