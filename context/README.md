# Context · Reynoso Toolchain

**EN DESARROLLO** · [Abrir página](https://reynosoch.github.io/context/) · [Volver al Toolchain](https://reynosoch.github.io/)

Convertir un repo ZIP, README y archivos de código en un paquete de contexto para continuar un proyecto con una IA.

## Alcance previsto

- Estructura, README, package.json y archivos importantes
- TODO, reglas, arquitectura y decisiones
- Últimos cambios proporcionados y prompt para continuar

## Ejemplos

- Preparar “PROMPT PARA CONTINUAR PROYECTO” con objetivo, restricciones y archivos.
- Compartir un repo sin pegar decenas de archivos manualmente.
