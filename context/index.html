Context.

Contexto del proyecto en un paquete.

Reunir un repositorio ZIP, README y archivos de código en un paquete de contexto para continuar el proyecto.

Herramienta en desarrollo.

Esta página presenta el alcance previsto. Aún no procesa archivos ni ejecuta acciones. La URL se mantendrá cuando la herramienta esté disponible.

FUNCIONES PREVISTAS

Alcance de la herramienta.

  • Estructura, README, package.json y archivos importantes
  • TODO, reglas, arquitectura y decisiones
  • Últimos cambios proporcionados y prompt para continuar

CASOS DE USO

Ejemplos.

  1. 01

    Preparar “PROMPT PARA CONTINUAR PROYECTO” con objetivo, restricciones y archivos.

  2. 02

    Compartir un repo sin pegar decenas de archivos manualmente.
