Lo que necesitas saber ＋

Instalable en iPad

En Safari usa Compartir → Agregar a pantalla de inicio. Se abre como app y guarda en caché la interfaz; para conectar con otro dispositivo todavía necesitas red.

Sesión local persistente

El código, rol, nombre del dispositivo, borrador corto y preferencia de recepción se guardan únicamente en este navegador. Tras F5 o un corte se intenta recuperar la misma sala. Pulsa Cerrar sala para borrar esa sesión.

Sin base de datos

Los archivos y mensajes no se suben a GitHub, Supabase ni otra base de datos. PeerJS solo ayuda a que las dos pantallas se encuentren; el contenido viaja por WebRTC.

Fotos y documentos de trabajo

Selecciona varios archivos: fotos, Excel, CSV, PDF, Word, PowerPoint, ZIP o cualquier otro formato. Se conserva el archivo original. Hasta 50 MB por archivo y 100 MB por selección.

Bandeja temporal

La sesión sí se recupera, pero los archivos ya recibidos siguen viviendo en memoria para no convertir el navegador en un almacén. Descarga lo que quieras conservar antes de recargar.
