MOTOR DE CONVERSIÓN

Una misma entrada, varias salidas.

Convert trabaja por contenido, no solo cambiando la extensión del nombre.

Word → PDF / TXT / ExcelLee DOCX y conserva el contenido textual para reutilizarlo.
Excel → PDF / Word / CSVLee la primera hoja XLSX y transforma filas/celdas.
CSV / JSON → Excel / Word / PDFTablas y datos estructurados pasan a documentos o hojas.
Imágenes → PDF / PNG / JPG / WebPRe-encode local con Canvas y PDF real.
Texto → PDF / Word / Excel / imagenTXT, MD, HTML, XML y otros formatos de texto.
PDF → TXT / Word / imagenDisponible cuando PDF.js puede cargarse en tu red.
ODT / ODS / PPTX → texto/documentoLectura básica del contenido XML interno.
