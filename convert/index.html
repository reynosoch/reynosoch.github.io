Procesamiento local.

La cola, las conversiones básicas y los archivos permanecen en el navegador. No se envían a Reynoso Toolchain ni se guardan en GitHub.

MOTOR DE CONVERSIÓN

Más entradas. Más cruces.

Convert reutiliza el contenido del archivo y realiza una conversión real entre formatos compatibles.

Office → Office / PDFDOCX, XLS/XLSX, PPTX, ODT y ODS pueden salir como documentos, hojas, slides o PDF.
Datos → múltiples formatosCSV, TSV, JSON, JSONL, YAML, XML y texto tabular pueden ir a Excel, Word, PDF, HTML y más.
PDF → editable / imagenExtrae texto para DOCX/TXT/HTML y renderiza páginas para formatos de imagen.
Imágenes → documento o textoPNG, JPG, WebP, GIF, BMP, SVG, AVIF, HEIC/HEIF y TIFF pueden convertirse o leerse directamente para copiar su texto.
Texto y código → documentoMarkdown, SQL, JS, TS, Python, CSS, logs, config, LaTeX y otros textos pueden salir en PDF, Word, HTML, EPUB o imagen.
Formatos abiertosODT, ODS, EPUB, XML, YAML, Markdown, SVG y RTF amplían los caminos sin depender de Office.
Carpetas → ZIP64Sube carpetas completas con subdirectorios y archivos pesados; genera un archivo ZIP conservando toda la estructura.
Lectura por bloquesProcesa archivos pesados con WebAssembly CRC-32 y streams sin cargar todo el contenido en memoria a la vez.
Motores bajo demandaLas librerías pesadas solo se descargan cuando un formato realmente las necesita.
PrivacidadSin cuenta, sin carga de documentos a un servidor y sin backend para las conversiones básicas.
